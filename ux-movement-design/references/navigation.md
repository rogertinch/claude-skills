# Navigation Reference — UX Movement Corpus

## Sidebars

**Scanability**:
- Group items under labeled sections (reduces search time)
- Use icon + label pairs (not icons alone; icon-only fails at >8 items)
- Consistent icon style throughout (filled vs outline — don't mix)
- Active state: filled icon + colored text + subtle background fill
- "3 Small Ways to Make Large Sidebars Scannable"
- "How to Group Your Sidebar Items for Better Findability"
- "How to Make Sidebar Menus Easier to Navigate"

**Color schemes**:
- Light sidebar on light app: low contrast, blends in
- Dark sidebar on light app: creates clear visual separation
- Sidebar color should use the 30% primary brand color allocation
- "Should Sidebar Icons Be Dark or Light?"

**Collapsed/space-saving sidebars**:
- When screen space is tight, use icon-rail mode with tooltips
- Don't go icon-only without tooltips
- "How to Design a Sidebar That Saves Screen Space"
- "How to Optimize Your Sidebar Menu for High Usability"

**Sidebar indicators** (notification badges, counts):
- Place count badges on the right edge of menu items
- Use colored dots for unread status, numbers for counts
- "The Optimal Design for Sidebar Indicators"

**Multi-level sidebar navigation**:
- Max 2–3 levels. Deeper = user loses orientation
- Expand sub-items inline (not flyout menus)
- "A Better Approach to Multi-Level Sidebar Navigation"
- "How to Handle Large-Scale Item Groups in a Sidebar"

## Mega Menus

**Grid layout > vertical list**:
- Vertical lists force sequential scanning
- Grid layout allows spatial/parallel scanning
- "The Megaton Problem with Mega Menus" — core article
- "Why Horizontal Lists Are Better for Mega Menus"
- "How to Simplify a 46 Item Mega Menu"
- "How to Simplify a Confusing 65 Item Mega Menu"

**Hover behavior**:
- Hover menus must be adjacent to (touch) the navigation bar
- A gap between nav and menu causes the menu to close when the mouse moves diagonally
- "Why Hover Menus Should Always Touch the Navigation Bar"

## Top Navigation Bar

**Item fit**:
- "How to Fit Many Menu Items in a Navigation Bar" — truncation + overflow patterns
- Priority+ pattern: show items that fit, collapse the rest into a "More" menu
- "The Best Location for Navigation Items on Web Apps"

**Sticky nav**:
- Use on content-heavy, long-scroll pages
- Skip on short pages and dashboards
- "When You Should Use a Sticky Navigation Bar"

## Mobile Navigation

**Tab bars** (bottom navigation):
- Best for 3–5 primary destinations
- Active tab: filled icon + label
- Inactive: outline icon

**Hamburger menus**:
- Acceptable for secondary items; bad for primary navigation
- "The Secret to an Engaging Hamburger Menu"
- "How to Fit Massive Menus on Mobile Screens"
- "Bento Box Menus: A Better Way to Navigate Lists"

**Breadcrumbs on mobile**:
- Show only immediate parent (not full chain)
- "How You Should Display Breadcrumbs on Mobile"

**Swipe navigation**:
- Use for content categories with few items (tabs → swipeable views)
- "Swipe Navigation: A Faster Way to Navigate Mobile Screens"

## Category Navigation / Content Tabs

**Horizontal scrolling tabs**:
- Good for 5–12 categories
- Show active indicator clearly (underline or fill)
- Don't let users lose the active tab during scroll
- "A Better Way to Navigate Content Categories on Mobile"
- "How to Design an Intuitive Category Carousel"

**Filter tabs (above list)**:
- Tabs as filters: show count badges on active filter
- "Little UX Details: Bad vs. Good Filters"

## Pagination vs Infinite Scroll vs "View More"

- Numbered pagination: good when users need to navigate to specific pages
- Infinite scroll: good for feeds/social content where all items are equivalent
- "View More" button: best default for most content lists — preserves scroll position
- "Why View More Buttons Are Better Than Pagination Links"
- "How to Display a Pagination of 100 Data Rows"
